JWT 검증 로직을 별도 모듈로 분리했다.

- 기존: 각 라우터마다 토큰 파싱 중복
- 변경: `verifyToken` 미들웨어 하나로 통합

```js
function verifyToken(req, res, next) {
  const token = req.headers.authorization?.split(' ')[1];
  if (!token) return res.status(401).end();
  // ...
}
```

**배운 점**: 미들웨어 순서가 생각보다 중요했다. 로깅을 인증 앞에 둬야 실패 요청도 기록된다.
